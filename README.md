## 🌟 Featured Project

### DIMASA AI — Artificial Intelligence & Innovation

**Multi-Sensor Data Fusion & Uncertainty-Aware Prediction System**

An environmental sensor intelligence project that combines multi-sensor data fusion, machine learning, and uncertainty quantification to develop data-driven environmental predictions.

**Key Components:**
- Multi-sensor data analysis and error evaluation
- Inverse-variance weighted sensor fusion
- Machine learning model development and evaluation
- Split Conformal Prediction for uncertainty quantification
- Interactive analytics dashboard built with Streamlit
- Automated testing and reproducible workflows

**Technology Stack:**

`Python` `Pandas` `NumPy` `Scikit-learn` `Streamlit` `Plotly` `Matplotlib` `Joblib`

🔗 **[Explore DIMASA AI Repository](https://github.com/DimasApril24/dimasa-ai)**

*Note: This project currently uses synthetic environmental sensor data for research and experimentation.*
